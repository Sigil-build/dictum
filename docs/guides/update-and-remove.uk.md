# Оновлення й видалення

Як оновити чи видалити Dictum, залежить від того, як ви його встановили. Хай там як, ваші налаштування, завантажені моделі, історія й ключі API у сховищі ключів залишаються: після оновлення чи повторного встановлення все буде так, як ви залишили. Як видалити й їх, описано в розділі [Почати з нуля](#start-fresh).

Програма сама каже, коли вийшла нова версія: у меню значка в треї з'являється **Доступне оновлення: 0.5.0** з цією версією, і цей пункт відкриває її сторінку на GitHub. Див. [Перевіряти оновлення](../reference/settings.md#check-for-updates).

У назвах пакетів тут замість версії стоїть `<version>`. Команди спершу записують версію в змінну, `version=0.5.1`: підставте ту, яку ви завантажили.

## Інсталятор для Windows {#msi}

**Щоб оновити**, відкрийте новіший `dictum-<version>-win-x64.msi`. Він закриває Dictum, замінює його й запускає знову.

Старішу версію поверх новішої інсталятор не ставить і пише "A newer version of Dictum is already installed." Щоб повернутися до старішої версії, спершу видаліть Dictum, а тоді встановіть стару.

**Щоб видалити:**

1. Відкрийте параметри Windows → **Apps** → **Installed apps** (в українській Windows ці назви перекладено).
2. Знайдіть **Dictum**, натисніть **…** поруч і виберіть **Uninstall**.

Під час видалення Dictum закривається, а разом із програмами зникають пункт у меню «Пуск» і запуск під час входу.

## Zip-архів для Windows {#zip}

**Щоб оновити:**

1. Закрийте Dictum: **Вийти з Dictum** в меню трею.
2. Розпакуйте новіший `dictum-<version>-win-x64.zip` і скопіюйте файли з його теки `dictum-<version>-win-x64` у свою теку Dictum, наприклад `C:\Tools\Dictum`, із заміною старих файлів.
3. Знову запустіть `dictum-gui.exe`.

Тека має лишатися тією самою: на неї вказує запуск під час входу.

**Щоб видалити:**

1. Вимкніть **Запускати Dictum під час входу в систему** в Налаштуваннях → **Загальні**, якщо це ввімкнено.
2. Закрийте Dictum: **Вийти з Dictum** в меню трею.
3. Видаліть теку.

## AppImage {#appimage}

Тут вважається, що AppImage лежить у `~/Applications/Dictum.AppImage`, як радить [Початок роботи](../getting-started.md#install).

**Щоб оновити:**

1. Закрийте Dictum: **Вийти з Dictum** в меню трею.
2. Покладіть новий файл на місце старого, під тією самою назвою, і зробіть його виконуваним:

    ```sh
    version=0.5.1
    mv ~/Downloads/dictum-$version-linux-x64.AppImage ~/Applications/Dictum.AppImage
    chmod +x ~/Applications/Dictum.AppImage
    ```

3. Запустіть його знову.

Під тією самою назвою запуск під час входу працює далі. Якщо ж ви тримаєте кожну версію під власною назвою, після першого запуску нового файлу вимкніть і знову ввімкніть **Запускати Dictum під час входу в систему** в Налаштуваннях → **Загальні**, щоб запуск під час входу вказував на новий файл.

**Щоб видалити:**

1. Вимкніть **Запускати Dictum під час входу в систему** в Налаштуваннях → **Загальні**, якщо це ввімкнено. Якщо під час входу у вас запускається лише демон, виконайте натомість:

    ```sh
    ~/Applications/Dictum.AppImage dictum daemon --uninstall-autostart
    ```

2. Закрийте Dictum: **Вийти з Dictum** в меню трею.
3. Видаліть файл AppImage.
4. У Wayland видаліть також прихований запис, за яким портал робочого столу впізнає Dictum:

    ```sh
    rm ~/.local/share/applications/dev.dictum.Dictum.desktop
    ```

## Архів tar.gz з install.sh {#tarball}

**Щоб оновити**, розпакуйте новіший архів і запустіть його `install.sh`, як під час першого встановлення:

```sh
version=0.5.1
cd ~/Downloads
tar -xzf dictum-$version-linux-x64.tar.gz
./dictum-$version-linux-x64/install.sh
```

`install.sh` просить запущений Dictum закритися, а тоді одним кроком замінює `~/.local/lib/dictum`. Запуск під час входу вказує в цю теку, тож працює й далі. Потім знову запустіть Dictum з меню програм.

**Щоб видалити**, виконайте:

```sh
~/.local/lib/dictum/uninstall.sh
```

Скрипт закриває Dictum і видаляє:

- програми в `~/.local/lib/dictum`;
- посилання `dictum` і `dictum-gui` у `~/.local/bin`;
- пункт меню й значки;
- записи запуску під час входу й запис для порталу, які запускають саме цю копію Dictum.

Наприкінці він пише, де лежать ваші налаштування й моделі: їх він залишає.

## Пакет для Arch {#pkgbuild}

**Щоб оновити**, зберіть пакет новішого випуску так само, як збирали перший: покладіть його `PKGBUILD` і `dictum-<version>-linux-x64.tar.gz` в одну теку й виконайте там `makepkg -si`. pacman замінить встановлений `dictum-bin`. Потім закрийте Dictum пунктом **Вийти з Dictum** в меню трею й запустіть знову, щоб працювала нова версія.

**Щоб видалити:**

1. Вимкніть **Запускати Dictum під час входу в систему** в Налаштуваннях → **Загальні**, якщо це ввімкнено. pacman не чіпає файлів у вашій домашній теці, а запис запуску під час входу — один із них.
2. Закрийте Dictum: **Вийти з Dictum** в меню трею.
3. Видаліть пакет:

    ```sh
    sudo pacman -R dictum-bin
    ```

4. У Wayland видаліть також `~/.local/share/applications/dev.dictum.Dictum.desktop` — прихований запис, за яким портал робочого столу впізнає Dictum.

## Що залишається після видалення {#kept}

Цього не видаляє жоден спосіб, тож після повторного встановлення Dictum знайде все як було, без майстра й без завантаження:

| Що | Windows | Linux |
| --- | --- | --- |
| Налаштування: `config.json` і ваші запити | `%APPDATA%\Dictum` | `~/.config/dictum` |
| Моделі, історія й журнали | `%LOCALAPPDATA%\Dictum` | `~/.local/share/dictum` |
| Ключі API | Диспетчер облікових даних (Credential Manager) | GNOME Keyring або KWallet |

Кожне з них описано на сторінці [Де Dictum зберігає файли](../reference/files.md).

## Почати з нуля {#start-fresh}

**Щоб налаштувати Dictum заново, але залишити моделі**, відкрийте Налаштування → **Загальні** → **Майстер налаштування** й натисніть **Запустити ще раз**. Майстер почне з того, що вибрано зараз.

Або закрийте Dictum і видаліть лише `config.json`, шлях до якого пише `dictum config path`. Під час наступного запуску відкриється майстер, як уперше, а моделі, що вже є на комп'ютері, не завантажуватимуться знову.

**Щоб видалити все:**

1. Видаліть збережені ключі API, поки конфігурація ще називає їх. Кожне `"apiKey": "secret:<name>"` у `config.json` — це один ключ. Перелічіть їх:

    === "Windows 11"

        ```powershell
        Select-String '"secret:' "$env:APPDATA\Dictum\config.json"
        ```

    === "Linux"

        ```sh
        grep '"secret:' ~/.config/dictum/config.json
        ```

    Потім видаліть кожен за назвою після `secret:`, наприклад, як нижче. У Windows запускайте `dictum` за повним шляхом: див. [Командний рядок](../getting-started.md#command-line).

    ```sh
    dictum secret delete dictum-processor-llm
    ```

2. Закрийте Dictum: **Вийти з Dictum** в меню трею.
3. Видаліть обидві теки:

    === "Windows 11"

        ```powershell
        Remove-Item -Recurse -Force "$env:APPDATA\Dictum", "$env:LOCALAPPDATA\Dictum"
        ```

        Програм це не зачіпає: інсталятор тримає їх в іншій теці, `%LOCALAPPDATA%\Programs\Dictum`.

    === "Linux"

        ```sh
        rm -rf ~/.config/dictum ~/.local/share/dictum
        ```

4. Запустіть Dictum. Він відкриє майстер налаштування, як під час першого запуску, і знову завантажить модель мовлення.
